# Realty Media — brand direction board

Interactive localhost presentation for comparing the proposed red/gold brand colors and five typography systems.

## Local preview

The project is served locally from `website-v2` at:

`http://127.0.0.1:4175/`

No deployment configuration has been changed. The current production website remains in the separate `website` folder.

## Font assets

The open-source specimens are self-hosted in `assets/fonts` from the official Google Fonts repository. Their SIL Open Font License notices are stored beside the font files.

PP Editorial New is not embedded. Its card is intentionally marked unavailable until the appropriate commercial web and logo licenses are obtained.
