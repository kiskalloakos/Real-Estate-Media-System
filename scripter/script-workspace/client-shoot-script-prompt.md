# Client Shoot Script Prompt

Use this prompt when you have a new property/client brief and want an 80%-ready shoot script.

```text
You are writing for Realty Media.

Write a short-form video script that gets our shoot 80% ready before we arrive.

Language:
[Romanian / English]

Property:
[property name/type]

Location:
[city/area + useful nearby context]

Audience:
[who should want this]

Client goal:
[bookings / sale leads / awareness / investor leads / launch]

Key facts:
- [fact 1]
- [fact 2]
- [fact 3]
- [fact 4]
- [fact 5]

Visual assets we can shoot:
- [visual 1]
- [visual 2]
- [visual 3]
- [visual 4]
- [visual 5]

Tone:
[natural, warm, premium, direct, playful, calm, cinematic, etc.]

Hard constraints:
- Do not invent facts.
- Keep Romanian natural, not translated from English.
- Tie every voiceover beat to something visible.
- Avoid long feature lists.
- Include a final CTA.
- Avoid lazy AI Romanian like "vibe de vacanta", "sejur confortabil", "momente de rasfat", or "instant intri in modul de vacanta".

Output:
1. HOOK 1
2. HOOK 2
3. HOOK 3
4. Final spoken script only, with natural line breaks
```

## Fast Romanian Cabana Example

```text
HOOK 1:
La mai putin de doua ore de oras, locul asta e facut pentru un weekend in care chiar te opresti.

HOOK 2:
Daca vrei doua zile in care sa nu mai alergi dupa nimic, incepe de aici.

HOOK 3:
Cabana asta e pentru weekendurile alea in care stai mai mult afara decat in telefon.

Suntem aproape de natura, intr-o cabana gandita pentru liniste, confort si timp petrecut impreuna.

Jos ai zona de zi, semineu si suficient spatiu pentru seri lungi cu familia sau prietenii.

Bucataria e utilata pentru mese simple, cafea dimineata si seri fara drumuri inutile prin oras.

Dormitoarele sunt simple, curate si comode, cu tot ce ai nevoie dupa o zi petrecuta afara.

Afara ai terasa, gratar si locul in care probabil o sa ramai cel mai mult: ciubarul.

Daca vrei date libere pentru urmatorul weekend, trimite-ne mesaj si iti spunem ce variante avem.
```
